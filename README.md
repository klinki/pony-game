# Pony Game

Let's make a beautiful game together.

Pony game is a web-based game where players take care of horses and race with them.

## Overview

The main goal of the game is to manage a stable of horses, ensuring their well-being and training them to become champions in races.

## Mini-games

The initial version of the game includes two main activities:

### 1. Barn
In the Barn mini-game, the player takes care of the horse. Activities include:
- Feeding the horse
- Cleaning the horse
- Bonding with the horse

### 2. Race
In the Race mini-game, the player races their horse against other horses. Performance depends on the horse's stats (Speed, Stamina, Strength) and potentially player interaction during the race.
